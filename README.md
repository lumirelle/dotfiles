# Dotfiles

My dotfiles (also application configuration files), out-of-box (for me).

## Configurations Included (By Category)

- Network Proxy Client
  - [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev): Require Bun global installation to run `.ts` setup scripts.
- Operator System Configuration
  - Windows Specific:
    - [~/.config/run_onchange_ui.cmd](dot_config/run_onchange_ui.cmd): Customize Windows UI font, use [~/.config/ui_reset.cmd](dot_config/ui_reset.cmd) to restore the default font
    - [~/.config/run_onchange_disable_ctrl_space.cmd](dot_config/run_onchange_disable_ctrl_space.cmd): Disable hotkey `ctrl+space` to switch input method language
    - [~/.config/run_onchange_disable_Windows_search.cmd](dot_config/run_onchange_disable_Windows_search.cmd): Disable Windows Search Service
    - [~/.config/run_onchange_LongPathEnabled.cmd](dot_config/run_onchange_LongPathEnabled.cmd): Enable Windows long path support
    - [~/.config/run_onchange_DeveloperModeEnabled.cmd](dot_config/run_onchange_DeveloperModeEnabled.cmd): Enable Windows Developer Mode, so WinGet (invoked by Mise) creates the command aliases of portable packages as symlinks under `%LOCALAPPDATA%\Microsoft\WinGet\Links` instead of appending one PATH entry per package
- Operator System Components
  - Windows Specific:
    - [Windows Subsystem for Linux (WSL)](https://github.com/microsoft/WSL)
    - [WinLibs: GCC + MinGW-w64 compiler for Windows](https://winlibs.com/)
      - [~/.config/run_onchange_set_cc_cxx.cmd](dot_config/run_onchange_set_cc_cxx.cmd): Set `CC` & `CXX` environment variable to force using `gcc` & `g++` instead of MSVC on Windows
- Input Method
  - Rime
    - [Weasel (Rime for Windows)](https://github.com/rime/weasel)
    - [Squirrel (Rime for macOS)](https://github.com/rime/squirrel)
    - [IBus Rime (Rime for Linux/IBus)](https://github.com/rime/ibus-rime)
    - [Fcitx5 Rime (Rime for Linux/Fcitx5)](https://github.com/fcitx/fcitx5-rime)
- Terminal
  - [Windows Terminal (Windows Only)](https://github.com/microsoft/terminal)
  - [Windows Terminal Preview (Windows Only)](https://github.com/microsoft/terminal)
- Shell
  - [Nushell](https://github.com/nushell/nushell): My interactive shell. Other shells are only used to run scripts.
  - [Windows PowerShell (5.1, Windows 11 Built-in)](https://learn.microsoft.com/en-us/powershell/scripting/overview?view=powershell-5.1)
  - [Bash](https://www.gnu.org/software/bash/): Implementation is depend on the specific operator system distribution
- Shell Mutiplexer
  - [Herdr](https://herdr.dev/)
- Shell Prompt
  - [Starship](https://starship.rs/)
- Dotfile Manager
  - [Chezmoi](https://www.chezmoi.io/)
- Dotfile, Package, Tool Manager
  - [Mise](https://mise.jdx.dev/)
- Source Controller
  - [Git](https://git-scm.com/)
  - [Jujutsu](https://github.com/jj-vcs/jj)
- Password Manager
  - [Fnox](https://fnox.jdx.dev/)
- Editor
  - [Neovim](https://neovim.io/)
  - [Zed](https://zed.dev/)
  - [VSCode](https://code.visualstudio.com/)
- Harness (for AI model, Harness + AI model = Agent)
  - [Pi Coding Agent](https://pi.dev/) & it's extensions:
    - [@gotgenes/pi-permission-system](https://pi.dev/packages/@gotgenes/pi-permission-system)
    - [@juicesharp/rpiv-web-tools](https://pi.dev/packages/@juicesharp/rpiv-web-tools)
    - [@juicesharp/rpiv-ask-user-question](https://pi.dev/packages/@juicesharp/rpiv-ask-user-question)
    - [pi-agent-browser-native](https://pi.dev/packages/pi-agent-browser-native)
    - [pi-session-cleanup](https://pi.dev/packages/pi-session-cleanup)
    - [pi-btw](https://pi.dev/packages/pi-btw)
- Misc Tool
  - [Yazi](https://yazi-rs.github.io/)
    - [~/.config/run_onchange_set_yazi_file_one.cmd](dot_config/run_onchange_set_yazi_file_one.cmd): Let Yazi use Git provided `file.exe`
